## 관리자 탐색 구성 · 2026-10-15

관리자 UI 재정리의 기능별 판단・권한・검증 기록은 [[Admin Operations Feature]]에 둔다. 이 문서는 화면 조합만 기록하며 운영 기준을 복제하지 않는다.

| 좌측 영역 | 조합하는 기능 | 관련 하위 업무 |
| --- | --- | --- |
| 대시보드 | 운영 개요 | 허용된 업무 진입점과 요약 |
| 성과 분석 | 방문 분석・마케팅・접속 국가/도시・태그 인사이트 | 방문·유입 분석 + 태그 인사이트(직접 항목) |
| 기사 운영 | 게시글 목록・새 글 작성・캘린더・카드뉴스・기사 채점・AI 채점기록 | 기본 업무 + 기사 검토(채점/기록) |
| 자료 관리 | 용어집・세계연맹 회원국・기사 참고 사이트・기념품 도감・도감 분류・행사 카탈로그・도감 댓글 승인 | 스카우트 자료 + 도감 운영 |
| 노출 관리 | 히어로 기사・메인 스토리・자동 추천 안내・홈 배너・게시판 설명・게시판 배너・티커 | 홈 편집 + 게시판 편집 |
| 운영·설정 | 버전기록・오류/이슈 기록・사이트 히스토리・KMS・내 계정・사용자 관리・프리셋 관리・태그/글머리・SEO/메타태그・저자/AI 고지・저자명 관리・도움 주신 분들・UI 번역・공개 메뉴명・개인정보 처리방침 | 운영 기록 + 편집 기준 + 사이트 기본설정 + 계정 관리 |

좌측 사이드바가 유일한 기준 탐색이다. 관련 하위 업무는 `details`/`summary`로 접고 현재 메뉴의 그룹은 열린 상태로 유지한다. `name="admin-tools"`로 한 하위 그룹씩 펼치는 네이티브 동작을 사용한다. 권한이 없는 항목과 항목이 없는 그룹은 숨기며, 본문에 같은 메뉴를 다시 만들지 않는다. 좁은 화면은 기존 사이드바 열기/닫기와 한 열의 본문 흐름을 사용한다.

기존 39개 항목의 업무/호환 진입을 보존하고 오너 전용 공개 메뉴명 진입점을 복원하여 재편 후 항목은 40개(버튼 39개 + KMS 링크 1개)다. 권한 카탈로그는 기존 35개 슬러그를 유지한다. `account-security`의 기존 진입은 내 계정으로 연결한다. KMS는 사이드바의 새 탭 링크 한 개를 유지하고, 홈페이지 확인 링크는 기존처럼 같은 탭에서 연다.

`03.156.00`의 로컬 합성 브라우저 18/18과 운영 버튼 39개 도달/민감 메뉴 OTP 취소 확인은 탐색·공통 화면의 증거다. 전체 내부 기능 검수와 구별한다. 사용자가 승인한 후속 작업은 성과 분석을 대시보드 바로 아래에 두고 모든 메뉴의 세부 입력·저장·목록·오류 상태와 화면 위계를 개선한다. 현재 구현·기능별 검증·배포 상태는 [[Admin Operations Feature]]에서 기록하며 로컬 합성 검증을 실제 멤버 로그인이나 실제 모바일 기기 검수로 표시하지 않는다.

후속 내부 개선 `03.157.00`은 런타임 `8d265232`로 운영에 배포했다. 40개 진입점의 내부 대응표와 로컬 UI 65개/API 60개 검사, 운영 자산·버전·공개 기사 회귀의 근거는 [[Admin Operations Feature]]에 있다. 새 버전의 로그인 전 화면은 확인했고, 정상 로그인 뒤의 실제 내부 자료 검수는 재로그인 대기 상태다.
